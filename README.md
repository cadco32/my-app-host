# Vacation Scheduler Application

Vacation Scheduler Application (VSA) is an Android app designed as an internal tool for Good Vibes Value Vacations Global, Inc. (GVVVG).
It assists vacation planners with the management of vacations for their clients.
Vacation Planning users can create and schedule vacations and daily excursions.

## Features

- Add, edit, delete Vacations and excursions
- Schedule Dates
- Reminder Notifications
- Share via common messaging platforms
- Report Generation
- Login access control
- Search 
- User Friendly UI with Portrait and Landscape compatibility

## Tech Stack

- Java
- Gradle
- Android SDK
- Room
- SQLite

## Installation Instructions

- Download app-release.apk from one of the following sources
    - [APK Download on Host webpage](https://cadco32.github.io/my-app-host/)
- Install onto android device or virtual device running compatible android version
    - Minimum OS version Android 8.0 (API: 26)
    - Maximum OS version Android 16 (API: 36)
- Enable Notifications permission

## Android APK Version

The signed APK is deployed for Android 8.0+ (API: 26+) and has been tested for compatibility with Android 16 (API: 36)
