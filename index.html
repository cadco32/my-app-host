Vacation Scheduler Application

Vacation Scheduler Application (VSA) is an Android app designed as an internal tool for Good Vibes Value Vacations Global, Inc. (GVVVG). It assists vacation planners with the management of vacations for their clients. Vacation Planning users can create and schedule vacations and daily excursions.

Features

  • Add, edit, delete Vacations and excursions
  • Schedule Dates
  • Reminder Notifications
  • Share via common messaging platforms
  • Report Generation
  • Login access control
  • Search
  • User Friendly UI with Portrait and Landscape compatibility

Tech Stack

  • Java
  • Gradle
  • Android SDK
  • Room
  • SQLite

Installation Instructions

  1. Download app-release.apk from this webpage.
  2. Install onto android device or virtual device running compatible android version.
    • Minimum OS version Android 8.0 (API: 26).
    • Maximum OS version Android 16 (API: 36).
  3. Enable Notifications permission.
